# Qur’anic concordance

The 1,268 indexed word positions occur in 998 different verses. The 23 groups below are disjoint at the word level and can share a verse. Counts use the [Quranic Arabic Corpus](https://corpus.quran.com/) morphology release 0.4. The [CSV](QURAN-CONCORDANCE.csv) identifies each word and segment. Verse lists here suppress repetitions within each group. These are lexical matches. Read the passage to determine who is speaking, what is being described and whether the use is approving, descriptive or critical.

## Reproduction and attribution

Each bold number is a surah. The numbers after it are ayahs. Download the morphology input from the [mirror repository](https://github.com/cltk/arabic_morphology_quranic-corpus/blob/master/quranic-corpus-morphology-0.4.txt). Use the raw file and run `python build_concordance.py INPUT.txt CHECK.csv` from this directory. Compare CHECK.csv with the published CSV. The script verifies the Git blob ID of the input. The [rules](concordance-rules.json) define every included root and lemma. [Corpus and Tanzil credits](CREDITS.txt)
